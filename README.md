A configurable big accumulator that contains the capacity of 24 normal ones, but takes 4 times the space, which is a 6x space gain.

In Space-Age, it's unlocked on Fulgora.

Initially planned to be a sprite replacement for Bio-industries.

Sprite by me, uses parts from Repair Turret (LGPLv3) (by Klonan, SacredAnarchy), Exotic Space Industries (GNU GPLv3) (by PreLeyZero, eliont) and Vehicle Radar (MIT) (by YuokiTani)
